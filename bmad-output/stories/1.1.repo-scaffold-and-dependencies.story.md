# 1.1: Repo scaffold and dependencies

**Story ID:** 1.1
**Epic:** 1 — Platform Foundation & Model Selection
**Slug:** repo-scaffold-and-dependencies
**Status:** ready-for-dev

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2–8 h). No story points.

## Story

As the **builder**,
I want **the monorepo layout, every planned dependency and the lint/import rules set up once**,
so that **all later stories can run in parallel without editing shared dependency or config files**.

## Acceptance Criteria

1. The repository has the ADR-038 layout:
   - `backend/app/<module>/__init__.py` for `core, crypto, auth, spaces, chat, assistant, guardrails, llm, documents, sheets, outputs, jobs, lifecycle, audit, compliance, admin, api, worker`
   - `backend/migrations/versions/`, `backend/tests/`
   - `parser/`, `frontend/`, `deploy/`, `evals/`
   - **no `prototype/` folder:** this is a clean repo (`invest-ai-llm`); the old prototype stays outside it
   - the existing `bmad-output/` planning folder is left untouched

   A root `README.md` describes the layout and links to `bmad-output/`.
2. `backend/pyproject.toml` (Python 3.13, uv) and `parser/pyproject.toml` declare every runtime and dev dependency listed in Dev Notes. `uv lock` succeeds for both, and the lockfiles are committed.
3. `frontend/package.json` (pnpm) declares every frontend dependency listed in Dev Notes. `pnpm install` succeeds and `pnpm-lock.yaml` is committed. `tsconfig.json` is `strict`.
4. `ruff check`, `ruff format --check`, `mypy --strict backend/app` and `lint-imports` all pass on the empty skeleton.
5. `.importlinter` encodes the ADR-038 rules (see Dev Notes):
   - no `fastapi`/`starlette` imports in `crypto, assistant, guardrails, llm, sheets`, or in `documents` except `documents.routes`
   - only `app.crypto` imports `cryptography`
   - only `app.llm` imports `openai`
   - domain modules never import `app.api`, `app.admin`, `app.chat`
6. `.gitignore` excludes `/data/`, `**/backups/`, `*.kek`, `.env`, `deploy/secrets/*` (except README), `node_modules/`, `dist/`, `evals/corpus/build/`, `evals/reports/`, `__pycache__/`. `.pre-commit-config.yaml` runs ruff, ruff-format and **gitleaks**.
7. A root `Makefile` provides targets `lint`, `typecheck`, `test`, `typegen`, `corpus`, `up`, `down`. Targets whose tooling arrives in later stories print a clear "not available yet" message instead of failing obscurely.

## Dev Notes

- **Module layout and dependency rules** are fixed by ADR-038:
  - only `crypto` imports `cryptography`; only `llm` talks to vLLM;
  - only `documents.ingestion` talks to the `parser` container;
  - only `spaces` defines `AccessContext`;
  - modules marked "NO fastapi imports" are plain Python.

  [Source: architecture.md#ADR-038]
- **Shared-file conventions:** dependencies are declared once here, and later stories must
  not edit `pyproject.toml` or `package.json`. Routers, routes, settings, audit events and
  readiness checks are per module. [Source: epics.md#shared-file-conventions-parallel-safety-rules-for-every-story]
- **Backend runtime dependencies** (pin via uv.lock):
  - Web and API: `fastapi`, `uvicorn[standard]`, `pydantic>=2`, `pydantic-settings`, `python-multipart`, `httpx`
  - Database: `sqlalchemy[asyncio]>=2`, `asyncpg`, `alembic`, `pgvector`
  - Shared state: `valkey`
  - Security: `pwdlib[argon2]`, `cryptography`
  - IDs: `uuid-utils` (UUIDv7 in Python)
  - Observability: `structlog`, `opentelemetry-sdk`, `opentelemetry-exporter-otlp`, `opentelemetry-instrumentation-fastapi`, `prometheus-client`
  - LLM: `openai`, `pydantic-ai-slim[openai]`
  - Guardrails: `presidio-analyzer`, `spacy`
  - Documents and sheets: `fastembed`, `polars`, `openpyxl`, `pypdfium2`, `python-docx`, `lark`
  - Jobs: `apscheduler>=3.10,<4`

  [Source: architecture.md#8-technology-stack] Valkey is chosen over Redis for its licence [Source: architecture.md#ADR-018]. Python 3.13's stdlib has no `uuid7`, hence `uuid-utils` [Inference].
- **Backend dev dependencies:** `pytest`, `pytest-asyncio`, `ruff`, `mypy`,
  `import-linter`, `faker`, `reportlab`, `python-pptx` (corpus generation, Story 1.7),
  `locust` (Story 7.11). [Source: architecture.md#ADR-037] [Inference for tool picks]
- **Parser dependencies:** `docling` (MIT), `rapidocr-onnxruntime`, `openpyxl`, `polars`,
  `pydantic`. The parser is a separate container with no app DB access. [Source: architecture.md#ADR-027]
- **Frontend dependencies:**
  - Runtime: `react@19`, `react-dom@19`, `react-router`, `@tanstack/react-query`, `@tanstack/react-table`, `react-markdown`, `rehype-sanitize`, `lucide-react`
  - UI: `tailwindcss@4`, `@tailwindcss/vite`, `class-variance-authority`, `clsx`, `tailwind-merge`, Radix primitives used by shadcn/ui (`@radix-ui/react-dialog`, `-dropdown-menu`, `-toast`, `-slot`, `-tabs`, `-tooltip`)
  - Dev: `typescript`, `vite`, `@vitejs/plugin-react`, `openapi-typescript`, `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`, `@playwright/test`, `@axe-core/playwright`, `eslint`, `typescript-eslint`, `eslint-plugin-react-hooks`

  [Source: architecture.md#8-technology-stack] [Source: architecture.md#ADR-008]
- **import-linter:** use `forbidden` contracts.
  - The fastapi ban needs `ignore_imports = app.documents.routes -> fastapi` (and `starlette`).
  - For the `openai` ban, set `allow_indirect_imports = True`, because `app.assistant` uses
    `pydantic_ai`, which imports `openai` internally. Only direct imports are banned.

  [Inference]
- **No secrets in the repo;** gitleaks runs in pre-commit and CI. [Source: architecture.md#ADR-021]
- **Backups live under `/data/backups`, never in the repo** (git-ignored as a safeguard). [Source: architecture.md#ADR-035]
- This is a **new, clean repository** (`invest-ai-llm`). The old Streamlit/Foundry Local prototype remains in the separate `foundry_local` folder for reference only and must not be copied in. [Source: decision-log.md#2026-10-07--new-repo-invest-ai-llm-prototype-dropped-project-renamed]
- Makefile delegation: when present, `make corpus` runs `evals/corpus/Makefile.inc` (Story 1.7), `make up/down` call `deploy/compose.yml` (Story 1.3), and `make typegen` calls `frontend/scripts/gen-api-types.sh` (Story 1.10). Later stories add their own include files instead of editing the root Makefile. [Inference]

## Testing

- **Approach:** static checks only; there is no feature code yet.
- **Key scenarios:** a clean checkout runs `make lint typecheck` successfully; a deliberate violation in a scratch branch (e.g. `import fastapi` inside `app/llm/x.py`) makes `lint-imports` fail.
- **Per-AC verification:**
  - AC #1 → directory listing matches the ADR-038 tree; no `prototype/` or `src/` folder exists; `bmad-output/` is unchanged (`git diff --stat bmad-output` empty).
  - AC #2/#3 → `uv lock --check` and `pnpm install --frozen-lockfile` succeed.
  - AC #4 → CI commands exit 0.
  - AC #5 → three negative probes (fastapi in `llm`, `cryptography` in `auth`, `openai` in `guardrails`) each fail.
  - AC #6 → `git check-ignore /data/x evals/reports/x` matches; gitleaks finds a planted fake secret.
  - AC #7 → each Makefile target runs or prints "not available yet".
- **Fixtures/mocks:** none.
- **Edge cases:** Python 3.13 wheel availability for `presidio-analyzer`/`spacy`/`fastembed`. If a wheel is missing, record it in the Dev Agent Record; do not silently drop the dependency.
