# 1.10: Frontend shell

**Story ID:** 1.10
**Epic:** 1 — Platform Foundation & Model Selection
**Slug:** frontend-shell
**Status:** ready-for-dev

## Story

As the **builder**,
I want **the React app shell with route auto-discovery, a secure API client, an SSE reader, a safe markdown renderer and shared formatting helpers**,
so that **every UI story adds screens without editing shared files and inherits the security rules**.

## Acceptance Criteria

1. `pnpm build` produces `dist/` from a Vite + React 19 + TypeScript (strict) app.
   - Routes are **auto-discovered** with `import.meta.glob('./routes/**/route.tsx')`. Each module exports a typed `route` object (path, element, `requiresAuth`, `roles?`).
   - The shell provides a layout (header, left navigation, content area) and an auth guard that redirects to `/login` on 401.
2. `src/api/client.ts` is the only fetch wrapper:
   - `credentials: 'include'`;
   - on non-GET requests it adds `X-CSRF-Token`, read from the `__Host-csrf` cookie;
   - it parses `application/problem+json` into a typed `ProblemError` (`status`, `code`, `title`, `correlationId`, extensions);
   - on 401 it triggers the login redirect.
3. `src/api/sse.ts` provides `readSSE(response): AsyncIterable<{event: string, data: unknown}>` for **POST** streaming responses: it parses `event:`/`data:` lines and multi-line data, and handles abort via `AbortController`.
4. The TanStack Query client has sensible defaults (no retry on 4xx, `staleTime` 30 s). `src/api/queryKeys.ts` is the central key factory. `scripts/gen-api-types.sh` generates `src/api/schema.d.ts` from `backend` OpenAPI (`python -m app.api.export_openapi`).
5. Tailwind CSS 4 + shadcn/ui base components (Button, Input, Label, Dialog, DropdownMenu, Table, Card, Badge, Tabs, Tooltip, Toast) live under `src/components/ui/`, with visible focus styles and WCAG AA contrast tokens.
6. `src/components/SafeMarkdown.tsx` renders markdown with `rehype-sanitize`:
   - **only links whose href starts with `cite:`** are rendered (as internal citation buttons via an `onCite(documentId, locator)` prop);
   - **no images, no raw HTML, no external links** (rendered as plain text).
7. `src/lib/format.ts` provides:
   - date/time in IST as `DD-MMM-YYYY` / `DD-MMM-YYYY HH:mm IST`
   - Indian grouping (`1,00,000`) and international grouping
   - `₹` crore/lakh helpers, percent with fixed decimals

## Dev Notes

- **Frontend state:** TanStack Query for server state; no Redux/Zustand. Local state with
  `useState`; current user and CSRF token via a `/auth/me` query + context (wired in 2.5).
  [Source: architecture.md#ADR-008]
- **Rendering rule:** only `cite:` links are rendered; never images, raw HTML or external
  URLs. Citation format is `cite:<document_id>#<locator>`, e.g. `p.12`, `slide 4`,
  `Sheet1!B2:F20`. [Source: architecture.md#ADR-025] [Source: architecture.md#ADR-008]
- **CSRF:** the double-submit token is in the `__Host-csrf` cookie (JS-readable). The
  session cookie `__Host-session` is HttpOnly and never touched by JS. Never store auth
  state in localStorage. [Source: architecture.md#ADR-006]
- **Problem format:** RFC 9457 with `code` and `correlation_id`. 404 is also used for
  not-accessible resources, so show "not found", never "forbidden". [Source: architecture.md#ADR-003]
- **SSE:** chat streams are a POST response, so `EventSource` can't be used. Event names:
  `meta`, `status`, `delta`, `table`, `sources`, `replace`, `plan`, `job`, `done`, `error`.
  [Source: architecture.md#ADR-002] [Source: architecture.md#ADR-025]
- Types are generated from OpenAPI and never hand-written; `schema.d.ts` is regenerated,
  never edited. [Source: architecture.md#ADR-002] [Source: epics.md#shared-file-conventions-parallel-safety-rules-for-every-story]
- Display formatting (IST, DD-MMM-YYYY) happens only in the frontend; the API sends UTC
  ISO-8601. [Source: architecture.md#ADR-003]
- Accessibility: WCAG 2.1 AA on core screens; Radix/shadcn primitives. [Source: prd.md#NFR-011]
- `package.json` deps are already declared (1.1); don't edit them. [Source: epics.md#shared-file-conventions-parallel-safety-rules-for-every-story]

## Testing

- **Approach:** Vitest + Testing Library unit tests; one Playwright smoke test (shell loads, unknown route shows 404 page).
- **Per-AC verification:**
  - AC #1 → adding a temporary `routes/demo/route.tsx` registers `/demo` without editing other files.
  - AC #2 → POST adds the CSRF header from `document.cookie`; a problem+json 422 becomes `ProblemError` with `code`; 401 triggers redirect.
  - AC #3 → a mocked `ReadableStream` with split chunks and multi-line data yields correct events; abort stops iteration.
  - AC #4 → `gen-api-types.sh` runs against an exported OpenAPI file.
  - AC #5 → axe check on the shell has no violations.
  - AC #6 → `[x](https://evil.example)`, `![i](http://x/y.png)` and `<img src=x>` render as text or nothing; `[p.12](cite:abc#p.12)` renders a button calling `onCite('abc','p.12')`.
  - AC #7 → table-driven tests: `100000 → 1,00,000`, `₹4,215.5 cr`, a UTC → IST date edge across midnight.
- **Fixtures:** a mock fetch, a stream builder.
- **Edge cases:** `javascript:` hrefs; `cite:` with a malformed locator (render as text); cookie missing (request proceeds without the header and the server rejects it).
