# 4.5: Output gate and final moderation

**Story ID:** 4.5
**Epic:** 4 — Guardrails & Data Protection
**Slug:** output-gate-and-final-moderation
**Status:** ready-for-dev

## Story

As a **banker**,
I want **every streamed answer checked for identifiers, ungrounded figures and external links before I see it, and moderated once complete**,
so that **I can trust every number, and nothing in an answer can leak data or carry a hidden link**.

## Acceptance Criteria

1. **Hold-back streaming (`guardrails/output_gate.py`, slot 6):** the gate session buffers model text into spans (sentence or line boundaries). Spans with no digit and no `@` are released at once as `Delta`. Spans with a digit or `@` are held until the span closes, then checked (AC #2–#3) before release. `finish()` flushes the remainder through the same checks. Released text is never altered afterwards except by a whole-answer `Replace`.
2. **Identifiers:** each held span is scanned with `identifiers.detect()`. Any unmasked high-risk value (including a value next to a `[PAN]`-style placeholder) → the gate emits `Replace(withheld_text, "identifier")` and drops all further model text for the turn. Placeholders alone pass through unchanged.
3. **Grounding:** the session's grounding set = sources added via `add_grounding()` (chunks, tables, tool cells, calculation results) + the user message + today's date. Each held span runs `grounding.ground_text()`; every ungrounded figure (or whole range) is replaced inline with "[couldn't verify]". A turn with ≥ 1 replacement records `grounding_failed` with the count.
4. **External content stripping:** before release, every span loses: URLs and bare domains, e-mail-style link targets, raw HTML tags, Markdown images, and Markdown links whose target is not `cite:<document_id>#<locator>` (the link text is kept). A `cite:` link whose `document_id` is not in the turn's selected set is reduced to its text.
5. **Final moderation (`guardrails/stage_final_moderation.py`, slot 7):** `guard_classify` on the user message + full visible answer; unsafe → `Verdict(safe=False, category)`, so 3.2 replaces the answer (`withheld`). A guard error or timeout is treated as unsafe (fail closed).
6. **Audit and performance:** `guardrails.output_screened` (counts: held spans, identifier withholds, ungrounded figures, stripped links; final moderation category) — counts only. Checks per held span ≤ 300 ms p95 on the dev machine (`@pytest.mark.perf`).

## Dev Notes

- **ADR-025:** tables come from engine data; hold-back gating — spans without digits or `@` stream immediately, spans with them are held and checked for (a) high-risk identifiers (no unmasked ID may ever be output) and (b) figure grounding; grounding set = this turn's retrieved chunks and tables (masked), tool sheet cells, operation and calculation outputs, the user's message, the current date; strip any URL, e-mail link target, HTML, or Markdown image/link not matching `cite:<document_id>#<locator>`; masked placeholders pass, but a high-risk value next to a placeholder is withheld. No token reaches the client except through the output gate. [Source: architecture.md#adr-025-output-gating-grounding-and-rendering-v2-supersedes-adr-011]
- **ADR-024 stages 6–7:** output gate (regenerate once, else replace); final moderation with Qwen3Guard on the full response → `replace`; errors → `replace` + `withheld`. [Source: architecture.md#adr-024-guardrail-pipeline-v2-supersedes-adr-010]
- **No regeneration in V1 of the gate:** FR-036 allows "regenerated, **or** the figure replaced with 'couldn't verify'". Inline replacement keeps the stream live and avoids a second model call; identifier hits withhold the whole answer. [Source: prd.md#fr-036-every-figure-in-an-answer-is-grounded--must] [Inference]
- **FR-015:** no unmasked identifiers; no external URLs, images or links, only internal citation links; a response that fails screening is withheld or replaced, and audited (metadata). [Source: prd.md#fr-015-responses-are-screened-before-display--must]
- **NFR-003:** output checks ≤ 300 ms p95. **NFR-006:** 0 external URLs, images or network requests produced. [Source: prd.md#nfr-003-guardrail-overhead--must-performance] [Source: prd.md#nfr-006-injection-and-jailbreak-resistance--must-security]
- **Plug-in point:** implement 3.2's `OutputGate` (`open(turn)` → session with `add_grounding`, `feed`, `finish`) and `FinalModeration`; `TurnInput` carries the selected document IDs for `cite:` validation. [Source: story 3.2]
- **Withheld text** lives in `output_templates.py` (the decline templates folder is 4.3's). [Inference]
- The frontend renders only `cite:` links and CSP `img-src 'self'` blocks beacons regardless (defence in depth; 1.10/3.4). [Source: architecture.md#adr-025-output-gating-grounding-and-rendering-v2-supersedes-adr-011]

## Testing

- **Approach:** gate unit tests feeding scripted chunk sequences; property tests (Hypothesis if available, else table-driven) for the stripper; one end-to-end turn through 3.2 with a fake agent.
- **Per-AC verification:**
  - AC #1 → "The term sheet says" streams immediately; "Revenue was ₹4,215 crore." is held until the full stop; chunk boundaries inside a number ("4,2" + "15") don't leak a partial figure.
  - AC #2 → a PAN produced by the model → `Replace(... "identifier")` and nothing after it; `[PAN]` alone passes; `[PAN] ABCDE1234F` withheld.
  - AC #3 → a figure present in an added chunk passes (incl. ₹ crore vs million variants); one absent becomes "[couldn't verify]"; a figure from the user's message passes; today's date passes.
  - AC #4 → `![x](http://evil/a.png)`, `<img src=…>`, `[click](https://x.y)`, `www.x.com`, `mailto:` all stripped; `[p.12](cite:<selected id>#p.12)` kept; `cite:` with a foreign ID reduced to text.
  - AC #5 → unsafe verdict → withheld; guard timeout → withheld.
  - AC #6 → `assert_no_content` on audit; perf marker per span.
- **Edge cases:** answer that is one long span with no boundary (flush at 400 chars); numbers in citations' locators (`p.12`) are exempt (4.4 exemptions); U+2212 minus from 10.4 formulas.

## Learnings from Previous Stories

- **4.4:** run `ground_text` on each held span and replace failing figures; use `range_span` to replace a whole range; build the set from chunks, tables, tool cells, calculation outputs, the user message and `ExplicitValue(date.today(), Unit.DATE, ...)`; audit `reason` counts only.
- **4.4:** `£5m` reads as unit-less `5m`; spelled-out numbers, European grouping and `5 m` are not handled — leave them, 4.7 records them.
- **10.4:** formulas use U+2212 for minus; treat formula text like any other answer text.
- **1.10:** `SafeMarkdown.tsx` already renders only `cite:` links on the client; this gate is the server-side guarantee.
